# AI 提示词优化器

将自然语言需求整理为清晰、可执行、可验证的 AI 提示词，帮助用户减少歧义并保留原本目标。

## 功能

- 提取任务目标、受众、交付物、输入和约束。
- 区分已知事实、合理假设和需要确认的信息。
- 生成可直接复制的提示词，按需加入占位字段、步骤和验收标准。
- 为事实类、创意类、编程或分析任务调整提示结构。

## 目录结构

```text
.
├── README.md
└── skills/
    └── ai-prompt-optimizer/
        └── SKILL.md
```

## 安装

将 `skills/ai-prompt-optimizer` 目录复制到支持 Agent Skills 的宿主所配置的技能目录中，再按该宿主的说明启用或刷新技能。不同宿主的技能目录和启用方式可能不同，请以宿主文档为准。

## 使用示例

```text
请把下面的需求整理成一个可直接交给 AI 的提示词，并标出我还需要补充的内容：
为新员工写一份内部安全培训材料，适合 30 分钟的培训。
```

也可以提供已有提示词并要求精简、补全边界条件或加入输出格式。

## 适用边界

本技能负责设计提示词，不代表执行提示词中的任务，也不声称提示词已在特定模型上测试。不要把密码、密钥或不必要的个人信息放入提示词。它不用于绕过安全规则、权限控制或法律义务；遇到有害或未经授权的目标，应改为安全合法的替代目标。
